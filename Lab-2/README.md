\# Lab 2 – Agile Backlog Creation \& Sprint Simulation



\## Project

\*\*Student Club Event Ticketing \& Budget Portal (SCETBP)\*\*



\## Objective

This lab focuses on converting the functional requirements from Lab 1 into an Agile backlog using Jira. The requirements were organized into Epics and User Stories, prioritized, estimated using Fibonacci story points, and planned across sprints.



\## Work Completed



\- Created \*\*4 Epics\*\* based on the major functional areas of the system.

\- Created \*\*12 User Stories\*\* under the respective Epics.

\- Assigned priorities to the User Stories.

\- Estimated User Stories using \*\*Fibonacci story points\*\*.

\- Planned and executed \*\*2 sprints\*\* in Jira.

\- Simulated the movement of User Stories through the sprint workflow.

\- Used the Jira Sprint Board to track sprint progress.

\- Reviewed the Sprint Reports and Burndown Charts.

\- Reflected on estimation, prioritization, sprint planning, and team capacity.



\## Epics



1\. \*\*Event Proposal Management\*\*

2\. \*\*Budget Request \& Approval\*\*

3\. \*\*Ticket Generation \& Management\*\*

4\. \*\*Event Monitoring \& Administration\*\*
